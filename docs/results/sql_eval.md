# NL-to-SQL evaluation

Execution accuracy on `evaluation/golden.yaml`: the generated query's result must match the gold query's result (see `src/analytics_copilot/eval/matching.py`). Brackets are 95% Wilson intervals. Generated by `scripts/eval_report.py`.

## Held-out result

The test split (37 SQL questions + 8 refusals) was run once, after prompt work on the dev split only:

- Execution accuracy: **30/37 = 81.1% (66%-91%)**
- Queries that executed: 95%
- Refusals correct: 88% (7 stopped by intent rules, 1 answered with fabricated data)

Failures on that run led to three changes (table-less queries are now rejected; a 'physical store' definition; a rule to group time with date_trunc) and one scorer fix (years as 2024 or 2024-01-01). Numbers below include those changes and are **no longer held-out**: the test questions have been looked at.

## Remaining failures (full pipeline)

| Id | Question | What went wrong |
|---|---|---|
| q07 | How many stores do we have in California, not counting online? | Business vocabulary: read 'not counting online' as channel = 'retail', dropping outlets. The semantic layer defines physical stores in the table description; the model ignores it. |
| q25 | What was revenue by region for physical stores in 2025? | Same as q07: 'physical stores' became channel = 'retail'. |
| q46 | How did Camping revenue in California compare between August and September 2026? | Invented a filter: added channel = 'online', which the question never mentions. |
| q52 | For each month of 2026, what was revenue and the percent change from the previous month? | Month-over-month change for January is NULL because December 2025 was filtered out before LAG. Defensible reading, but not the answer to 'change from the previous month'. |
| q53 | What was the return rate of the Granite Peak Summit Down Jacket for orders placed March through May 2026? Use returned lines divided by lines sold. | Ambiguous column in a join; the correction loop did not recover in 3 attempts. |
| q54 | What was the average number of items (order lines) per completed order in 2025? | Semantics: averaged units (SUM(quantity)) instead of counting order lines, though the question says 'order lines'. |
| q55 | What was revenue per dollar of marketing spend in each state in 2025? | Wrong grain: computed revenue per marketing dollar per state per month instead of per state. |
